# Conference interpreter training

A GitHub Pages-ready static website with an interactive English–Chinese consecutive interpreting exercise.

## Content
- `index.html` — landing page with exercise card
- `exercises/heforshe.html` — 39 segments of the HeForShe speech, English text-to-speech, adjustable speed, hidden/reveal Chinese translation

## Publish with GitHub Pages
1. On GitHub, create a **public** repository called `conference-interpreter-training`.
2. Upload `index.html` and the complete `exercises/` folder to the repository root (preserve the folder structure).
3. Open **Settings → Pages** and under **Build and deployment**, select **Deploy from a branch**.
4. Select **main**, folder **/(root)**, and save.
5. Once deployed, visit `https://YOUR-USERNAME.github.io/conference-interpreter-training/`.

Audio requires a browser/device with Web Speech API speech synthesis support. No backend is required.
